# Origin 科研图格式

从可编辑的 Origin 工程修改格式，交付保存后的工程和 EMF。保持既有标注、科学数据、单位、样本身份、曲线顺序、坐标范围和刻度数值；若发现图文或数据疑点，在清单中记录，依据当前任务另行处理。

## 格式标准

| 对象 | 标准 |
| --- | --- |
| 所有文字 | Arial，全部加粗（Bold） |
| 横、纵坐标长名称；存在时包括 Z 轴 | 36 pt |
| 坐标刻度标签 | 30 pt |
| 图例文字 | 20 pt |
| 数据曲线 | 3 pt |
| 坐标轴、主刻度线、次刻度线 | 3 pt |
| 正式图文件 | EMF |

正文单位中的数学上下标按 36 pt 基准自然缩放，保留数学含义。修正与 Arial 加粗标准冲突的内嵌字体、常规字重或斜体覆盖；保留富文本中的科学内容、符号和数学格式。其他注释沿用既有字号，字体统一为 Arial 并加粗。刻度标签必须显式启用加粗，不能只加粗坐标长名称和图例。优先通过位置、间距和页边空白解决遮挡，保持绘图区的比例与科学坐标不变。

## 样本配色

由当前项目提供已确认的“样本身份—色值”映射。不要按曲线顺序推断样本身份，也不要将某一研究项目的样本名和配色带入另一个项目。转速、掺杂比例等条件系列沿用其已确认配色。

## 操作与核验

编辑前核实工程、图窗口、数据列及样本对应关系，保存一份可恢复的源版本。批量任务按来源文件建立输出索引，记录待核项目，避免把格式合规当作科学结论已核实。

Windows 下通过 Origin 命令行或 COM 自动化时，先读 [references/origin-windows.md](references/origin-windows.md)，其中包含已实测的字体初始化、线宽单位和保存注意事项。使用已有可靠接口；不要仅凭命令执行成功判断格式生效。

保存修改后的独立工程，导出 EMF，并从 EMF 本身渲染预览。检查长名称、刻度、图例和注释是否完整、遮挡或越界。重新打开保存的工程，核验字体、加粗状态、字号和线宽；对比编辑前后的数据、样本映射及坐标范围。EMF 字体核验应检查实际绘制文字使用的字体和字重：包括轴名称、刻度、图例、现有注释及数学上下标，均应为 Arial 加粗（Windows LOGFONT weight 为 700），不能仅检查字体名称或未使用的字体定义。

交付可编辑工程、EMF、用于查看的预览，以及简短的文件对应和核验记录。若原生 EMF 包含位图区域，如部分 OpenGL 三维图，明确记录这一导出特性。
