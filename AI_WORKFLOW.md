# AI-assisted workflow design

The author independently turned repeated scientific-figure tasks into assistant instructions and supporting scripts.

1. Define protected scientific content: sample identities, units, coordinates, built-in labels, and numerical values.
2. Encode role-specific formatting rules and application-specific cautions in SKILL.md and reference documents.
3. Separate source-panel preflight from composition. Require normalized contact-sheet inspection before placement.
4. Use scripts for reproducible bounds, frame detection, collision constraints, common scaling, document anchors, and output records.
5. Inspect rendered output and refine failure rules for cropped labels, font initialization, opacity collisions, and inconsistent source styles.

The workflow's distinguishing feature is executable support for assistant decisions, plus visible acceptance artifacts. Origin source modification, EMF previewing, DOCX composition, and Word rendering are separate steps; no numerical scientific conclusions are inferred from a successful export.
